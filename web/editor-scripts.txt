# MAWE editor scripts are inlined in this order by edit.py and the Tauri build.
# Paths are POSIX and relative to web/. Keep runtime/bootstrap modules before the
# modules that consume their exports; this file is the only build order, the
# directory layout below it is for navigation and carries no order semantics.
# editor/playback/jkl.js owns JKL playback state; editor/boot/entry.js initializes
# its UI at load and consumes it through the window.MaweJklPlayback facade.
# editor/lib/* publish internal symbols on window.MaweLib and read each other
# lazily inside function bodies, so their mutual order is free; only load-time
# initializers need their owner first. Within that block editor/lib/namespace.js
# must come first (it creates window.MaweLib) and editor/lib/compat-surface.js
# last (it snapshots the whole surface into the window.AsrEditorUtils compat exit).
